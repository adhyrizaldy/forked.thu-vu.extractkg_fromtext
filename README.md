## Run Locally

Jalankan dalam virtual environment

Clone the project

```bash
  git clone https://github.com/adhyrizaldy/forked.thu-vu.extractkg_fromtext
```

Go to the project directory

```bash
  cd my-project
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run start
```


## Demo

Output pertama: Graph Network dari teks  -> knowledge_graphcreated.html

Output kedua: berupa Graph ter-filtered -> knowledge_graphcreated_kgspesifik.html
